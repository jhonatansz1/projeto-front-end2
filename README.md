# 💻 Projeto Front-End 2

Aplicação web desenvolvida para realizar cadastros, exibir listagens e gerenciar formulários de forma simples e organizada.

## 🚀 Funcionalidades
- Cadastro de itens/usuários
- Listagem de dados
- Preenchimento e envio de formulário

## 🛠️ Tecnologias Utilizadas
Este projeto foi desenvolvido com as seguintes tecnologias:
- **HTML5**
- **CSS3**
- **JavaScript**
